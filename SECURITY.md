# Security Policy

## Maintainer

Security maintainer: Arkadiy Ayrapetov (GitHub: korpus91)

## Reporting a vulnerability

Please report suspected vulnerabilities privately by email to Arkadiy@aglitch.com, or through GitHub's private vulnerability reporting on this repository. Do not open a public issue for security problems.

Expect an acknowledgement within 7 days. Confirmed issues are fixed and disclosed in a release note crediting the reporter unless they prefer otherwise.

## Scope

This tool is designed to be read-only. Any behavior that modifies system state, exposes data outside the local report folder, or can be abused to escalate privileges is in scope.
